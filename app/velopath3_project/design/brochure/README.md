# VeloPath Brochure

В этой папке лежит двусторонняя A4-брошюра под складывание втрое.

Файлы:
- `velopath-brochure-outside.svg` — внешняя сторона: обложка, задняя панель, клапан.
- `velopath-brochure-inside.svg` — внутренняя сторона после раскрытия.
- `assets/velopath-logo-source.png` — исходный логотип, встроенный в макет.

Параметры макета:
- Формат: A4 landscape
- Размер холста: `3508 x 2480 px`
- Сетка: 3 вертикальные панели
- Назначение: печать или экспорт в PDF

Рекомендации по печати:
- Печатать в масштабе 100% без автоматического подгона.
- Для двусторонней печати включить переворот по короткой стороне только после проверки ориентации на тестовом листе.
- Перед массовой печатью лучше сделать один пробный экземпляр и проверить линии сгиба.

Что можно быстро менять:
- Заголовки и тексты прямо в SVG.
- Палитру в блоке `<style>`.
- Логотип можно заменить файлом в `assets/velopath-logo-source.png` или перепривязать в теге `<image>`.
