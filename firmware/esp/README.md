# ESP-зона проекта (единая папка)

Путь: `C:\Users\vladimir.DESKTOP-L4RFPI0\Documents\velopath\firmware\esp`

Назначение: здесь хранится **всё, что связано с ESP**, включая исходники, вспомогательные инструменты, временные каталоги и артефакты сборки.

## Структура

- `esp32_at_bridge` — исходники и документация ESP32 AT/UART-bridge.
- `firmware++` — отдельное дерево ESP-прошивки, включая `.pio` и dev-артефакты.
- `tools_from_app` — ESP-утилиты, вынесенные из общего дерева приложения.

## Правило хранения

- Любые новые ESP-файлы, логи, сборки, кэши и промежуточные результаты складывать только в эту папку.
- В не-ESP разделы проекта (документация/STM32/app) ESP-мусор и артефакты не добавлять.
